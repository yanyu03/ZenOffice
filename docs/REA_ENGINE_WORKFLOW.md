3. 区分静态声明、函数行为假设和运行对照。资源或字符串存在不能证明功能可用；反编译不是原始源码。将支持的结论转换为独立实现的引擎契约与任务，不将厂商代码、资源或反编译输出导入公开仓库。
4. 在 Rust 实现后，用独立预期、自制输入及保存重开检查验证；兼容性结论需要原生宿主或指定参照物的功能对照。保留未通过和未测项，不以工具自检替代引擎验收。
